# pair-programming-plugin

Build repo for **pair**: a Claude Code plugin + CLI that keeps the engineer at the center of AI-assisted development.

- `docs/pair-DESIGN.md` explains why it works the way it does.
- `docs/pair-SPEC.md` is what to build (the source of truth).
- `docs/archive/` holds how the idea evolved, including early pilot drafts. It's history only.
- `CLAUDE.md` gives Claude Code its instructions for building this repo.

Start a Claude Code session here and say: *"Read CLAUDE.md and the two docs. Confirm the §2 decisions with me, then prepare build step 0."*
